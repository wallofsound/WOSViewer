## Symbolaxlar (förenklad Thoresen)

- **Masse:** pitched / dystonic / complex  
- **Energy:** impulse / sustained / iterated / accumulation / …  

GUI-paletten mappar till `ScoreSymbolKind`.

## Auto-klassning (heuristik)

Från segmentets duration, medel-ZCR, centroid-varians:

- kort + låg ZCR → pitchedImpulse  
- lång + låg ZCR → pitchedSustained  
- kort + hög ZCR → complexImpulse  
- lång + hög ZCR → complexSustained  
- hög novelty-densitet → iterated / accumulation  

Alltid redigerbart av användaren.
